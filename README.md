# Recruitment Tracker (Salesforce)

A recruitment management app built on Salesforce.

## Features
- Duplicate application and closed-position checks (Apex trigger, handler pattern)
- Auto-close position when openings are filled
- Batch + Schedulable job to close expired positions
- LWC dashboard: position search, applications table, apply form
- Record-triggered Flow for offer emails
- Permission sets, roles, reports and dashboard

## Tech
Apex, LWC, Flow, SOQL, SFDX
